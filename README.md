# FisioDigestivo IA

Aplicación educativa en Streamlit basada en las clases de Sistema Digestivo parte I y parte II.

## Secciones
1. Recorrido digestivo
2. Órganos y funciones
3. Órganos accesorios
4. Viaje del alimento
5. Práctica en tres tandas

## Tandas de práctica
- Fundamentos
- Aplicación
- Clínica sencilla

## Diseño
- Navegación tipo archivador de colores
- Adaptado a PC y celular
- Retroalimentación inmediata

## Ejecución local
```bash
pip install -r requirements.txt
streamlit run app.py
```
